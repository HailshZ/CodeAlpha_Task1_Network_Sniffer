# CodeAlpha Task 1: Network Sniffer

## 📡 Overview
A Python-based network packet sniffer built using **Scapy** that captures and analyzes live network traffic. This tool extracts source/destination IPs, protocols, ports, and TCP flags (SYN, ACK, RST, FIN) in real-time.

## 🎯 Why This Project
- Understand the fundamentals of network communication.
- Detect scanning activity (e.g., Nmap SYN scans).
- Demonstrate practical knowledge of packet headers and the OSI model.

## 🛠️ Features
- Captures live packets on any network interface.
- Identifies TCP, UDP, and ICMP protocols.
- Extracts and displays TCP flags.
- Detects SYN scan patterns.
